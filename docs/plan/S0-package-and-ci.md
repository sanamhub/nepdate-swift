## Tasks

  `.iOS(.v15), .macOS(.v12), .watchOS(.v8), .tvOS(.v15), .visionOS(.v1)`, product
  `.library(name: "NepDate", targets: ["NepDate"])`, target `NepDate`, test target `NepDateTests`

  added in S4-01, not now.
- `.swift-format` (JSON): defaults plus `"AllPublicDeclarationsHaveDocumentation": true` and
  `"ValidateDocumentationComments": true` under `rules`, `lineLength` 100.
- `.spi.yml`: `version: 1`, `builder.configs: [{documentation_targets: [NepDate]}]`.
- `CHANGELOG.md` with an empty `## [Unreleased]`.
- AC1: `swift build` and `swift test` pass on Windows and Linux with only the generated skeleton
  file from S0-02 in `Sources/NepDate/`.
- AC2: `Package.swift` has no `.package(` call.

### S0-02 Generator skeleton (`Tools/Codegen`)
- `Tools/Codegen/Package.swift`: tools 6.0, executable target `codegen`, no dependencies
  (Foundation is fine here: dev time only).
- Run from the repository root as `swift run --package-path Tools/Codegen codegen`. If
  `shared/VERSION` doesn't exist in the current directory, print
  `codegen: run from the repository root` and exit 1.
- Reads `shared/data/calendar/bs-calendar.json` with `JSONDecoder`. `month_lengths` is an object
  keyed by year string: sort the keys numerically, never rely on dictionary order. Checks
  `min_year == 1901`, `max_year == 2199`, 299 years, 12 lengths each, every length in 29...32; any
  failure prints the year and exits 1.
- Writes `Sources/NepDate/Calendar.generated.swift`. Line 1
  `// Generated by Tools/Codegen. DO NOT EDIT.`, line 2 `// swift-format-ignore-file`, then for now
  only `enum CalendarData { static let minYear = 1901; static let maxYear = 2199 }` (internal).
  Line endings LF, file ends with one newline.
- `--check`: generate in memory, compare with the file on disk byte for byte, print the first
  differing line and exit 1 on drift, without writing.
- AC1: two runs give identical bytes.
- AC2: after appending a space to `Calendar.generated.swift`, `codegen --check` exits 1.

### S0-03 CI scripts (`scripts/ci.sh`, `scripts/ci.ps1`)
- Both run the gates in ADR-0004 in that order, print each command before running it, stop at the
  first failure and end with one line `ci: N/7 gates passed` (or `ci: failed at gate K: <name>`).
  Gates that don't apply yet print `skipped` (ADR-0004).
- Coverage (gate 4): `coverage-check`, a second executable target in `Tools/Codegen`, reads the
  JSON path printed by `swift test --show-codecov-path`, sums covered and total lines over files
  whose path contains `/Sources/NepDate/` (and `/Sources/NepDatePatro/` once it exists), and exits
  1 under 90 %. `ci.sh` runs it on Linux only; on macOS and in `ci.ps1` it prints `skipped`.
- `ci.ps1` is PowerShell 7 and mirrors `ci.sh` step for step; no WSL, no bash.
- AC1: `ci.sh` and `ci.ps1` exit non-zero when a file under `Sources/` is not formatted (test by
  adding two blank lines inside a declaration).
- AC2: both print the summary line as their last line.

### S0-04 GitHub Actions and community files
- `.github/workflows/ci.yml` on `pull_request` and push to `main`: jobs `macos` (`macos-latest`,
  latest stable Xcode), `linux` (container `swift:6.4`), `windows` (`compnerd/gha-setup-swift`
  with the 6.4 release) running `scripts/ci.sh` or `scripts/ci.ps1`; job `shared-check` calling the
  hub's reusable `shared-check.yml`. Every action pinned by full commit SHA with the version in a
  comment; `permissions: contents: read`; `concurrency` cancels superseded runs on the same ref.
- `.github/workflows/shared-sync.yml`: the hub's reusable `shared-sync.yml` with
  `regenerate: swift run --package-path Tools/Codegen codegen`, weekly (Tuesday 03:15 UTC).
- `.github/dependabot.yml` (`github-actions` weekly; `swift` for `Benchmarks/` only, added in S5),
  `.github/pull_request_template.md` (task IDs, what and why, how tested, "What to look at first"),
  `.github/ISSUE_TEMPLATE/bug_report.md` (input, expected, actual, package version, Swift version,
  OS), `SECURITY.md` (private advisory, first reply within a week), `CONTRIBUTING.md` (points to
  `AGENTS.md` and the writing style).
- Human tasks: create `sanamhub/nepdate-swift`, branch protection on `main` requiring the three OS
  jobs and `shared-check`, environment `production` with a required reviewer.
- AC: CI green on the first PR, all four jobs.
