# ADR-0008: Read the patro counts from the hub's summary, not from literals

- **Status:** accepted
- **Date:** 2026-10-31
- **Approved by:** Sanam
- **Amends:** ADR-0001 §6 (codegen also reads `shared/spec/vectors/patro-summary.json`)

## Context

The patro tables have counts that follow the data: the coverage years, first and last day and
serial, days, tithi first and last day and serial, tithi days and names, holidays, event days,
events, distinct event names, distinct names and their UTF-8 bytes. Codegen pinned the coverage
serials, and the tests pinned every count, so a real data change, such as the BS 2084 New Year
rename, fails CI until someone edits numbers. The hub now generates
`spec/vectors/patro-summary.json` from the same data, and every port vendors it as
`shared/spec/vectors/patro-summary.json` (hub PATRO §3).

## Decision

1. Codegen reads `shared/spec/vectors/patro-summary.json`, checks every data-derived count and
   range edge it generates against it, and derives `coverageFirst` and `coverageLast` from
   `first_serial` and `last_serial`. A mismatch fails with the field and both values; a missing
   file fails with a message to re-sync `shared/`.
2. Every table entry still comes from `shared/data/patro/`, and the summary's serials equal the
   data's edges, so the same data gives the same generated bytes.
3. The library keeps only the invariants its lookups need, such as indexes fitting their types. It
   does not pin a count that a data update changes.
4. The tests read the summary at run time through `Tests/NepDatePatroTests/TestSupport.swift` and
   compare each generated table and the coverage with it, so dropped or duplicated data still fails
   them.
5. ADR-0002 §3 keeps the table sizes it records as facts of their day.

## Consequences

- A hub data update that passes the hub's own vector check reaches this port without editing a
  number: codegen and the tests follow the summary.
- A port whose `shared/` predates the summary fails codegen with an instruction to re-sync it, and
  neither the generator nor the patro tests can pass until it does.
